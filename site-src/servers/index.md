# Preparing servers

PASeasyInstall installs CyberArk PAM onto servers you provide. It does not create, size or manage the servers
themselves. Use physical machines, virtual machines or cloud instances, whatever your lab runs on. This section lists
what each server needs before you start an installation.

<div class="grid cards" markdown>

-   **[Roles and sizing](roles.md)**: which servers a lab needs, and how much CPU, memory and disk each one needs.
-   **[Server prerequisites](prerequisites.md)**: operating system, WinRM, SSH, accounts and network access.
